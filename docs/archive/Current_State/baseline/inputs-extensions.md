Permission precedence is first match: configured rules, then sidecar rules, then built-in workspace rules only if configured `default` is absent. Explicit `default: ask` suppresses those implicit rules just as explicit allow/deny does. Built-in rules allow read/search/edit/delete/move within workspace and think; fallback is ask. Sidecars carry rules, never a global default; operator configuration outranks machine-written grants. Rules are reread per permission request, unlike most bootstrap configuration.
