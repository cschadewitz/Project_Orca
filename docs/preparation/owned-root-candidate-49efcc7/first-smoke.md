# Inactive first owned-root smoke

`first-smoke-inputs.json` is a proposed launch payload for workflow `cal-codex-work` v3. It is not a launch record and has not been submitted. The first approved run should use one agent and this read-only task, after the owner has reviewed activation and rollback. Later independent runs may overlap only within an owner-set admission and capacity limit; this workflow prompt does not enforce that limit.

The smoke uses Git and shell built-ins only. A new root worktree does not inherit `node_modules`, and installs are outside the authorized scope. Do not substitute a package test or install. The assigned root must resolve to the recorded `workspace.cwd`, have the recorded `workspace.branch` (`orca/roots/<runId>`), expose `workspace.rootProvisioning.baseCommit` equal to `expectedHead`, and begin at that same HEAD with no project changes. The source repository must contain the pinned commit before admission. The owner should inspect the resulting owned-root receipt, branch and worktree registration, run status, and the two required `.orca/reports` artifacts; `codex-result.json` must record the actual Git commands/results, `No source changes.` in the patch, and no source commit. A mismatch or missing prerequisite is blocked and should be preserved for review, without resetting or removing the root.
