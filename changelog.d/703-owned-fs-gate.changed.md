- **agents:** ORCA's own file executor now follows the permission policy (#703). When an agent reads or writes through ORCA's ACP file callbacks, each call is decided just before the I/O: a denied path is refused even if the agent never asked, and a path the policy asks about is read or written only after a person allows that one operation once. The policy is checked again after the answer, so a deny saved meanwhile still wins. Agents' native tools are unchanged and still need an operating-system boundary.
