- **agents:** ORCA's own file executor now follows the permission policy (#703). When an agent reads or writes through ORCA's ACP file callbacks, each call is decided just before the I/O: a denied path is refused even if the agent never asked, and a path the policy asks about is read or written only on a one-time allow for that path in that turn, either the one the agent's own ask received or one ORCA asks for on its behalf. Each allow covers one call. Agents' native tools are unchanged and still need an operating-system boundary.
