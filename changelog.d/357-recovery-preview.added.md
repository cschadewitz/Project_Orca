- **cli:** `orca recovery <runId> [--checkpoint <nodeId>] [--json]` previews how a run could be recovered without changing anything: Resume, New run and Checkpoint attempt, each with why it is or is not available; the steps whose effects are uncertain because they started and did not complete; and, for a failed run, which steps a checkpoint attempt would reuse and which ran after it last time. Approvals and permissions are never carried forward. Starting a checkpoint attempt is not available yet.
