- **app:** the Runs surface has a **Search** view next to Tree and Board: event text and text artifact contents, asked of the daemon's `search`, each hit opening its step, run or artifact by its canonical link. It says when the daemon cut the scan short, and is visibly unavailable on a daemon that does not answer `search`.
- **daemon:** a caller limited to some runs can search without naming one: it searches its own run catalog, the runs `runs.list` shows it, decided before the scan, instead of being refused. The run list, run and event reads, artifact previews and search now share that one boundary.
