- **agents:** plain-language permission rules are switched on (#701). Once you configure a judge on your own API key (`review.plainRules.judge`, Anthropic or an OpenAI-compatible endpoint), grant it disclosure (`orca auth issue --judge-disclosure`) and create its daily budget (`orca judge budget init`, Linux and macOS), a rule written as a sentence can allow a single read or search you would otherwise have been asked about. Written deny and ask rules still decide first, nothing is saved as a standing grant, and every call the judge does not allow goes to you, with its reason shown on the ask. Until every step is in place, the Config surface's checklist says which is missing and nothing changes. See [docs/plain-language-rules.md](docs/plain-language-rules.md).
