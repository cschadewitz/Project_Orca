- **agents:** plain-language permission rules can now be switched on (#701). They stay off, and existing configurations behave as before, until you opt in with `review.plainRules.enabled: true`. Once you also configure a judge on your own API key (`review.plainRules.judge`, Anthropic or an OpenAI-compatible endpoint), grant it disclosure (`orca auth issue --judge-disclosure`) and create its daily budget (`orca judge budget init`, Linux and macOS), a rule written as a sentence can allow a single file read that ORCA performs for the agent. Reads and searches the agent makes itself, edits and commands still go to you (for edits and commands, with the judge's view shown as advice). Nothing is sent when any part of the call's description would contain one of the session's secret values. Written deny and ask rules still decide first, nothing is saved as a standing grant, and every call the judge does not allow goes to you, with its reason shown on the ask. The Config surface's checklist says which step is missing. To turn it off, set `enabled: false`. See [docs/plain-language-rules.md](docs/plain-language-rules.md).
