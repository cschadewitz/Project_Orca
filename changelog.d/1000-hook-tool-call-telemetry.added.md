- **agents, engine, store:** an agent can keep a record of every tool call its native pre-tool hook decides (`agents[].diagnostics.toolCalls: keep`, off by default, kept `diagnostics.retainDays` days, 30 by default). The hook hands each record to ORCA through an owner-only spool ORCA creates; ORCA validates every line as untrusted input, stamps the run and session itself, redacts the session's secret values and stores it, marked as reported by the hook, under the store's `diagnostics/tool-calls/`. Recording never changes a hook's answer. Records come only from hooks that emit them, which arrive with the hook adapters (#704, #705).
- **cli:** `orca diagnostics tool-calls (runs | export <runId> [sessionId] | delete <runId> [sessionId] | prune)`.
