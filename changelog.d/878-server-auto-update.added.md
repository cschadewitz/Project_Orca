- **server updates:** servers can update themselves from their ring on the update feed. Opt in with `autoUpdate` in `deployment.json` and `orca-release.py install-timer`. A systemd user timer stages each offered server bundle while work continues and activates it only when the server is idle (never outside quiet hours). It rolls back automatically if the new daemon fails before admission reopens, never rolls back once admission has reopened, never crosses a store format change, and keeps the last two releases. Operators can stop every server from activating anything, staged releases included, with the feed's servers' stop switch (**Server feed (stop or resume)**), or one server with an `auto-update.stop` file. A staged release is reused only when it was verified from the exact signed files the feed offers now, and the stop, quiet hours and the offer are checked again just before activation.
