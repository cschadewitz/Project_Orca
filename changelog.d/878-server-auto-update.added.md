- **server updates:** servers can update themselves from their ring on the update feed. Opt in with `autoUpdate` in `deployment.json` and `orca-release.py install-timer`. A systemd user timer stages each offered server bundle while work continues and activates it only when the server is idle (never outside quiet hours). It rolls back automatically if the new daemon fails before admission reopens, never rolls back once admission has reopened, never crosses a store format change, and keeps the last two releases.
