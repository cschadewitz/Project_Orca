- **agents:** `claudeCode: { settingSources, sandbox }` on a Claude ACP agent. `settingSources` chooses which of Claude Code's user, project and local settings files it reads (`[user]` leaves the checkout's `.claude/settings*.json` out, so a repository cannot add rules or servers ORCA did not choose); managed policy settings are not affected and still take precedence. `sandbox: on` (with `settingSources: []`, since loaded files would merge their own exceptions in) runs Bash in Claude Code's OS sandbox, failing the session if it cannot start and still asking about every command; sandboxed commands cannot write ORCA's store or read-only files, or read its private paths, but can read the store's ordinary state.
