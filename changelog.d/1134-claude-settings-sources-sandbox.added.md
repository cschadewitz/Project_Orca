- **agents:** `claudeCode: { settingSources, sandbox }` on a Claude ACP agent. `settingSources` chooses which of Claude Code's own settings files it reads (`[user]` leaves the checkout's `.claude/settings*.json` out, so a repository cannot add rules, hooks or MCP servers ORCA did not choose); `sandbox: on` runs Bash in Claude Code's OS sandbox, failing the session if it cannot start, keeping ORCA's private paths out, and still asking about every command.
