- **agents:** Cline CLI (`cline --acp`) is a supported agent at version 3.0.75, on this computer (Linux x64 tested). ORCA checks the launch before starting it: the executable's SHA-256 must be the published 3.0.75 build, only `--acp` and its own `--config` directory (holding nothing but Cline's own settings), Cline's sessions in the agent process (`CLINE_SESSION_BACKEND_MODE=local`, not its background hub), auto-update off, no other `CLINE_*` variable, the API key only as a secret, and no Cline hooks, plugins or MCP servers of its own. It refuses any other Cline version at the handshake, gives Cline's permission asks the paths and commands its policy needs (Cline sends neither), keeps Cline's auto-approve option off, rejects Cline sub-agents (whose tools Cline runs without asking), and answers "Always allow" with "Allow once". See docs/agents/cline.md.
- **app:** first-run setup names a configured `cline` executable as a Cline CLI candidate.
