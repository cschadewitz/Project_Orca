- **agents:** An agent reading a file that does not exist through ORCA's ACP file callback now gets "Resource not found" instead of a generic internal error, so agents that check for a file by reading it (Gemini CLI among them) can create new files. Only a file the host positively reports as absent (a local open that finds nothing, or the SFTP server's own no-such-file status) is answered that way; a failed SSH connection or any other read error is still reported as an error. The answer comes only after the permission policy allows the read, so a refused path still reveals nothing about whether it exists.
