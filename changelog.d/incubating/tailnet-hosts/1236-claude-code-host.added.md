- **cli/app:** Claude Code can be installed on a managed server from this computer, like Codex and
  GitHub Copilot CLI (#1236): `orca-cli remote agent install <host> --agent claude`, or
  **Install** under **Agents** in the app. ORCA never signs Claude Code in. You run its own sign-in
  on the server with your own account, and `status` and the app show the one command to run
  there.
