- **app:** In the connection dialog, **Agents** on a set-up machine's profile lists the agents
  ORCA can put there (Codex, GitHub Copilot CLI) and the state of each one (#1236): whether it is
  installed and signed in, or why an install is not usable. **Install** carries the pinned
  packages from this computer and shows the server config that runs the agent. **Sign in** runs
  the agent's own sign-in there and shows its code. **Open sign-in page** opens the page in your
  browser.
