- **release:** a signed prebuilt headless server, `orca-server-X.Y.Z-linux-x64.tar.xz` (bundled CLI, daemon and ACP facade, pinned Node runtime, shipped workflows and templates), with a SHA-256 manifest signed keylessly by the release workflow, from the 0.8 release line on. A final is published only with it; a release candidate gets it shortly after publication. `orca-release.py stage --bundle vX.Y.Z` (and `update --bundle`) verifies the signer and digest before unpacking and stages it with only Python 3 on the server.
