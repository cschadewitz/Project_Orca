- **release:** every release, final or rc, carries a signed prebuilt headless server, `orca-server-X.Y.Z-linux-x64.tar.xz` (bundled CLI, daemon and ACP facade, pinned Node runtime, shipped workflows and templates) with a SHA-256 manifest signed keylessly by the release workflow. `orca-release.py stage --bundle vX.Y.Z` (and `update --bundle`) verifies the signer and digest before unpacking and stages it with only Python 3 on the server.
