- **agents:** ORCA's protected-path check now judges a write through a link whose target does not exist yet by where the link leads, judges a delete or rename by the directory entry itself, and treats a path it cannot resolve for any reason other than absence (a loop of links, no permission) as protected. Before, a link in the workspace pointing at ORCA's not-yet-created permission sidecar was taken as a new workspace file, so a default-allowed edit could create the sidecar (#706).
