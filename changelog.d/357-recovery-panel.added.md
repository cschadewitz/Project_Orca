- **app:** The run summary has a Recovery section for a run that stopped. It shows how the run could be recovered and why each way is or is not available, lets you mark a step that may have acted outside ORCA to run again or abandon the run there, and starts a checkpoint attempt from a completed step. An unresolved start is kept by the app across navigation, reload and restart and asked again with the same request, so it never starts a second attempt; a reserved attempt is finished by reconciling it. `admissions.reconcile` takes `kind: "run.recover"` and then refuses any other kind of receipt before doing anything. A step reused by a checkpoint attempt, and a step's effect review, are shown in its detail.
