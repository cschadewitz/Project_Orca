- **update feed:** a server channel for the signed server bundle, from the 0.8 release line on. It has the same rings (`internal`, `preview`, `stable`), rollouts, pause switch and watchdog as the desktop channel. New tokens can be limited to the server channel (`feed-token.js RING --server`). Publishing feeds a release's server bundle before its Windows installers, and a ring's desktops are never offered a version that its servers are not all on.
