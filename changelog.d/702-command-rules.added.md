- **core, agents, daemon, app:** Permission rules can match a shell command by its words: `command: "npm *"` allows every npm command, and a deny for `git push` placed before an allow for `git *` gives "all git except push". An allow must cover every part of a compound command (`&&`, `;`, `|`) and never covers `sudo`, `bash -c`, a variable or a redirection, so `npm test && curl … | sh` still asks. A deny also catches the words with options in between (`git -C repo push`). The "Always allow" review offers wider command rules (`npm run *`, `npm *`) alongside the exact command, and the Config surface shows and edits the new **Command** field. A config holding a command rule must declare `version: 2`, and a permission sidecar holding one is written as version 3, so ORCA 0.7.x refuses them rather than reading them as every command. Where an agent's title is not its command, the exact "always" rule now names the command instead of the title.
