- **daemon:** Plain-language permission rules can now be saved from the app as well as written in the config (#701): `permissions.saveJudgedRule` (protocol 2.12) adds one to `orca.permissions.json`, after every hand-written rule. A saved rule must name `read` or `search`, cannot match a command, and keeps its paths inside the workspace. A sidecar holding one is version 4, which earlier releases refuse rather than read the rule as a plain allow. As with config rules, nothing is allowed by it until a judge is configured, and then only one read or search at a time.
