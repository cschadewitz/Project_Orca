- **app, daemon, agents:** **Always allow** and **Always deny** on a permission card now show the exact rule ORCA would save, the agent it is for and a lifetime (1 hour, 1 day, 7 days, 30 days or until removed; 7 days by default) before anything is written. Only **Save rule and allow/deny** saves it. A rule with a lifetime records `expiresAt` in `orca.permissions.json` and stops deciding at that instant without anyone editing the file; the Config surface shows when each rule expires. Protocol 2.8 adds `standing` to `inputs.list` entries, `durationMs` to `inputs.answer`'s `always` (at most 90 days) and `expiresAt` to effective rules in `config.get`. A file holding a timed rule is written as `orca.permissions.json` version 3, which ORCA 0.7.x refuses (it asks instead of allowing) rather than reading the rule as permanent; it goes back to version 1 when no timed rule is left. Saving a rule echoes the preview's `previewRef`, and the daemon refuses with `CONFIG_STALE` if the rule it would write is no longer the one shown.
