- **agents:** an agent with `driver: claude-agent-sdk` runs on an SSH host (#1130). The SDK and ORCA's permission bridge stay on ORCA's machine; only `claude` runs on the host, started over its SSH configuration as the person's own login there, with that machine's Claude Code and sign-in and none of the daemon's environment. Environment values go to the remote shell over the connection's stdin, never a command line, and the host's side owns `claude`'s process group: every session end stops it there over a new connection and confirms it gone. A `claude` that is not signed in there is refused with `claude auth login` guidance that names the host. Every call it makes is a person's to allow (no rule allows one, since ORCA cannot check a directory on that machine); secret references and `nativeToolHook: experimental` are refused there.
