- **agents:** Plain-language permission rules can now be written in the config (#702): `judge: { criterion: "..." }` instead of a `decision`. When a judge is configured (not yet available in the app or CLI), a rule like this can allow a single read or search the person would otherwise have been asked about. That happens only when no deny or ask rule matches, only for files ORCA checked are inside the workspace and not its own, and only once per call. Every other case is decided by the usual rules.
