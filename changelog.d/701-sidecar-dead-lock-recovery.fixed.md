- **agents:** On Linux, if ORCA stops in the middle of writing `orca.permissions.json`, the lock it leaves is now cleared automatically by the next write once the process that took it is no longer running in the same process namespace (#701). This applies only in a workspace private to your user (not writable by group or others). A writer that is only slow keeps its lock. Locks that cannot be attributed this way, locks in shared directories, and any lock on macOS or Windows still need removing by hand.
