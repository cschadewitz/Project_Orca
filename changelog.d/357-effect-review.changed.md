- **engine, cli:** A step that may have changed the workspace or external systems and never finished (a crash, a lost connection or a broken lease mid-step) is no longer run again on its own. `orca resume` and `orca run` refuse with `EFFECT_REVIEW_REQUIRED`, naming the step, before writing anything; `orca recovery review <runId> <stepRunId> --run-again|--abandon [--note text]` records your decision in the run's log, and resume then runs the step again, or the run ends cancelled. A step paused on purpose (an agent waiting on an answer) resumes as before. `orca recovery` blocks the options that would run an unreviewed step again, and its `--checkpoint` flag is now accepted.
- **engine:** A step's retry budget (`maxAttempts`, `completion.maxAttempts`) no longer repeats an attempt that may have acted outside ORCA. An agent step that already sent the agent a prompt fails instead of retrying, and waits for `orca recovery review`; a failure before the first prompt is still retried. A plugin node is retried only when its executor reports the attempt did nothing outside ORCA with `failed(code, message, details, true, "none")`.
