- **agents:** GitHub Copilot CLI (`copilot --acp`) is a supported agent at version 1.0.114, on this computer (Linux x64 and macOS arm64 tested). ORCA checks the launch before starting it and refuses flags and variables that approve tools up front, a token written into the config or inherited from the daemon's environment, a missing `COPILOT_HOME` or `--no-auto-update`, and any other Copilot version. It never sends Copilot a prompt that starts with a slash command (Copilot runs `/allow-all on` from a prompt), refuses to turn on Copilot's allow-all option or autopilot mode and ends a session that reports either on, and answers Copilot's "Always allow" with "Allow once" so every later call is asked about again. See docs/agents/copilot-cli.md.
- **app:** first-run setup names a configured `copilot` executable as a Copilot CLI candidate and says what ORCA needs from its profile.
