**Desktop builds are unsigned and unvalidated.** No Windows, Linux or macOS file attached
to this prerelease is code-signed or notarised, and none has installed-artifact acceptance.
If Windows SmartScreen, your browser or macOS Gatekeeper warns about or refuses a file,
**stop there** and report what it said; do not override the warning. The macOS `.dmg` and
`.zip` use the new bundle ID `com.schadewitz.orca` (was `dev.orca.desktop`), so OS
permissions, notifications and Keychain access do not carry over; upgrading an existing
Mac install is not a validated path, and no Mac acceptance is claimed.
