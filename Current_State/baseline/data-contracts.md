## Atomicity, schemas and compatibility

Implemented: JSONL appends take a keyed queue plus filesystem lock, allocate a sequence and repair a non-newline tail before writing. Readers can skip invalid JSON lines; schema-invalid parsed events are a different case. There is no global ordering between separate logs. Document stores reload under a lock, merge collection entries, write a temporary file and rename; caches compare file metadata. That protects collection replacement but is not an atomic read-modify-write business transaction across callers or files.
