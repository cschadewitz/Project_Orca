# Coverage matrix

This matrix covers every discovered workspace package and the major components defined below. **Traced** means architectural responsibilities and the listed boundary flows were inspected in source; it does not mean every line or branch was audited. **Mapped** source files in the census are accounted for but not all individually read. Tests are supporting/declaration evidence only.

Granularity: a major component owns a cohesive service, lifecycle, protocol boundary, persistence family or UI surface family. Closely related helpers remain in their owning component; a file is not automatically a component. Package views show internal families; linked detailed views expand substantial subsystems.
